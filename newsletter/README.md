# newsletter/ — 아이고 아침 메일

매일 아침 7시 뉴스레터는 구글 앱스 스크립트로 보내요. 이 폴더의 `Code.gs`는 그 스크립트의 사본이에요.
실제로 돌아가는 것은 aigo.artricx@gmail.com 계정의 앱스 스크립트 프로젝트 '아이고 메일'이에요. 고칠 때는 여기와 그쪽을 함께 고쳐요.

- **발송**: 7시부터 5분마다 `content/오늘날짜.json`이 사이트에 있는지 보고, 있으면 '아이고 구독자' 시트의 구독자(`active`)에게 한 통씩 보내요. 하루 한 번, 낮 12시까지.
- **구독**: `subscribe.html`의 신청 칸 → 웹 앱(`doPost`) → 확인 메일 → 확인 링크(`subscribe.html?a=confirm&t=…`, 페이지가 웹 앱에 대신 알려 줘요) → `active`.
- **그만 받기**: 메일 맨 아래 링크(`subscribe.html?a=unsubscribe&t=…`) → `unsubscribed`.
- 확인·그만 받기 링크를 웹 앱 주소로 바로 걸지 않는 까닭: 브라우저에 구글 계정이 여러 개 로그인돼 있으면 구글이 "현재 파일을 열 수 없습니다" 화면을 띄워요.
- **알림**: 특이사항은 `OWNER_EMAIL`로 '[아이고 알림]' 메일.
- **메일 모양**: 피그마 '메일 · 뉴스레터 (휴대폰 375 / 컴퓨터 600)' 시안을 따라요. 컴퓨터 값을 기본으로 쓰고, 480px 이하 화면은 `@media`로 글자와 간격을 줄여요. 소식 색은 색 가이드(분홍·노랑·초록·파랑)를 쓰고, 예전 글의 빨강은 그날 쓰지 않은 색으로 바꿔요.
- **메일 그림**: `assets/email/`의 로고(`logo.png`), 나한테는요 아이콘(`icon-me.png`), 앱 아이콘(`app-icon.png`), 스토어 배지 두 개. 피그마에서 3배 크기로 내보낸 그림이에요. 사이트에 올라가 있어야 메일에 보이니, 그림을 바꾸면 **PR 병합 → 스크립트 붙여 넣기** 순서로 해요.
- **미리보기**: `node newsletter/preview.js YYYY-MM-DD` → `preview/메일-YYYY-MM-DD.html`(저장소에 올리지 않아요). 실제 메일로 확인하려면 앱스 스크립트에서 `sendTestToMe`를 실행해요.
- **한도**: 일반 Gmail 계정은 하루 100명까지 보낼 수 있어요.
- 구독자 주소는 저장소에 넣지 않아요(구글 시트에만 있어요).
- 웹 앱을 새로 배포해 주소가 바뀌면 `subscribe.html` 신청 칸의 `action` 주소도 바꿔요.
