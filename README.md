# AILAB

매일 아침 7시, 그날의 AI 소식을 누구나 읽기 쉽게 일러스트와 인포그래픽으로 정리하는 블로그입니다.

- 홈: `index.html` (`posts.json`과 `templates/index.template.html`로 `scripts/build.py`가 만듭니다)
- 글: `posts/YYYY-MM-DD.html`
- 스타일: `assets/style.css`, 글자 크게 보기: `assets/site.js`, 일러스트: `assets/illust/`
- 매일 발행 절차와 글쓰기 규칙: `CLAUDE.md`

새 글은 `daily/YYYY-MM-DD` 브랜치의 Pull Request로 올라오고, 병합하면 GitHub Pages에 발행됩니다.
