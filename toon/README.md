# 인스타툰 〈엄마와 딸〉

아이고 소식 하나를 엄마와 딸의 생활 속 네 칸 만화로 바꾼 인스타그램용 만화예요.
블로그·앱과는 따로 움직이는 작업이라, 매일 발행 작업(`CLAUDE.md`)과 섞지 않습니다.

- `make_toon.py` — 네 칸 그림 한 장 + 대사 → 편마다 1080×1350 다섯 장(표지 겸 첫 칸, 칸 2~4, 오늘의 진짜 소식)
- `sheets/` — 편마다 고른 네 칸 그림(2×2, 글자 없음). 힉스필드 gpt_image_2_5 · high · 4k · 4:5
- `logo.png` — 통통한 글자 로고(그림). 글꼴이 아니에요
- `fonts/` — 주아(Jua, SIL OFL). 대사·제목 모두 이 글꼴 하나

## 만들기
```
pip install pillow playwright && playwright install chromium
python3 toon/make_toon.py 출력폴더        # 세 편 모두
python3 toon/make_toon.py 출력폴더 ep5    # 한 편만
```

## 새 편을 더할 때
1. 대본(네 칸)을 쓰고, 그림을 2장 뽑아 손·자세·사물을 확인해 1장을 고릅니다.
2. `sheets/epN.webp`로 넣고 `make_toon.py`의 `EPS`에 대사와 말풍선 위치를 적습니다.
3. 만든 다섯 장을 직접 열어 말풍선이 얼굴을 가리지 않는지, 글자가 다 읽히는지 봅니다.

그림체·글자 규칙·디자인 컨셉은 프로젝트 문서 '아이고-홍보-자동화'가 원본이에요.
